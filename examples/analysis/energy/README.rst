In this example, we will demonstrate the statistical analysis of the AFQMC energy
using `afqmctools`.
`afqmctools` is, of course, necessary to run the examples as shown below.
`afqmctools` can be installed using the instructions in `utils/README.md`

The `scalar_stats` script can be used to analyze the energy samples 
generated by AFQMC - saved in the `qmc.s000.scalar.dat` file.
Run `$ scalar_stats qmc.s000.scalar.dat -t -x time -e 10.0` to average the AFQMC energy, 
estimate the stochastic uncertainty (i.e. the statistical error bars),
and (using the `-t` switch) generate a plot of the AFQMC energy versus total projection time,
similar to the one below.

.. image:: imgs/n2_energy.png
  :width: 400
  :alt: N_2 AFQMC energy vs. total projection time.

The plot is useful for confirming that the AFQMC calculation has equilibrated by the 
equilibration time specified using `-e [equilibration time]`.

Additionally, in the panel on the right, there is a histogram of the AFQMC energy samples
which should be normally distributed around the AFQMC average.
The mean and standard deviation of the AFQMC energy samples is
ploted in both panels allowing the energy vs projection time curve (left panel),
and the distribution of energies (right panel) to be visually compared with
these values.
